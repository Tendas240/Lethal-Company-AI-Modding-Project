## Important probability semantics

DawnLib evaluates these AnimationCurves and converts the result to an integer spawn amount using rounding behavior. Scaling every native curve value/tangent by `0.5` is therefore an exact 50% **curve-amplitude / spawn-weight** reduction while preserving native curve shape and relative moon/tag behavior.

It is not a mathematical guarantee that a short observed run will contain exactly half as many objects. Runtime validation should focus on successful contract application, functionality and an overall lower occurrence rate rather than exact short-sample statistics.
