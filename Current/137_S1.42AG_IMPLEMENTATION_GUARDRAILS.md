# S1.42AG Implementation Guardrails

This file records non-negotiable implementation constraints derived from the exact LethalMinNightly 1.1.108 source and the project-local patch safety policy.

S1.42AG implementation must:

- patch only exact declared `LethalMin.MouthDogPikminEnemy.DoCheckInterval()` for the new Mouth Dog protection;
- use a `Priority.First` prevention-only prefix;
- validate exact declaring type, `void`, zero parameters and non-null method body before patching;
- refuse guessed fallback targets;
- leave `MouthDogPikminEnemy` enabled;
- leave `PikminEnemy.Update()` unpatched;
- leave Pikmin -> Mouth Dog attack/latch/death lifecycle native;
- leave Mouth Dog -> player behavior native;
- leave LethalMin Eyeless Dog cooldown/limit config unchanged;
- avoid delayed state repair, forced release and component disable;
- preserve all S1.42AF behavior outside the rebuilt local compatibility plugin.

The existing exact `PikminAI.GrabPikmin(Transform,float,int)` guard remains a separate proven mechanism for Crawler/Thumper and Baboon Hawk and is not the preferred primary Mouth Dog boundary.
