## Decision

A deterministic selector for **Circus Facility / `CircusFacilityFlow` on Offense** is technically designable by reusing the repository-proven **selector-only one-postfix architecture** already validated end-to-end by AGDIAG1, DRDIAG1, LFDIAG1, SHDIAG1 and TWDIAG1.

The reusable architecture is:

> Apply exactly one postfix to `LethalLevelLoader.DungeonManager.GetValidExtendedDungeonFlows(ExtendedLevel, bool)`, ordered after the accepted S1.42AB normalizer at `Priority.Last`; on the validated real Offense server-selection path, verify that exactly one already-returned Circus Facility wrapper exists with `DungeonName == "Circus Facility"`, exact `DungeonFlow.name == "CircusFacilityFlow"`, and final normalized rarity `100`; only then reduce that fresh returned list to the same existing wrapper as a singleton.

This preflight authorizes **no source implementation, compile, build, publication, Gale import, activation or runtime execution**.
