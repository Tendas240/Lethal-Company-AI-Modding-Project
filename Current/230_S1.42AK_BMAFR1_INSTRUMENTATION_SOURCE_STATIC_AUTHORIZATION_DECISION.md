## Feasibility result by observation surface

### Dusk selection state — authorized with mandatory refinement

The exact deployed Dusk source proves the selection body:

`EntityReplacementRegistrationPatch.ReplaceEnemyEntity(orig_Start orig, EnemyAI self)`

and the exact non-default application callsite:

`StartCoroutine(current.Apply(self))`.

The source/static implementation must **not depend on an unproven separately patchable `DuskEnemyReplacementDefinition.Apply(EnemyAI)` declaration** merely to learn which definition was selected.

Instead, it must instrument the exact already-proven selector body with a narrowly validated transpiler callback immediately before the unique non-default `current.Apply(self)` call. That callback may read `current` and `self` and record definition Unity object name/instance ID, concrete type and `IsDefault`; it must leave the original call and operands unchanged.

This is narrower because it observes the already-selected local value and does not replay Dusk weights or RNG.

For no/default/existing-replacement outcomes, **absence of the non-default callback alone must never be mislabeled as a proven default state**. The source/static checkpoint must either:

1. validate exact side-effect-free Dusk lookup contracts and capture the specific selector outcome; or
2. instrument exact selector branches with read-only outcome markers.

If that cannot be proven without fuzzy scans or semantic replay, the implementation must fail closed or emit `SELECTION_STATE_INCONCLUSIVE`. It may not fabricate `DEFAULT` or `NO_REPLACEMENT`.
