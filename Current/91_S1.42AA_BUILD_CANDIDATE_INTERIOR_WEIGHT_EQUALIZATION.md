## Why this candidate exists

The accepted S1.42Z LethalLevelLoader configuration already contains project-normalized dungeon tag weights `Vanilla:100,Custom:100`, but its global option `Inject Dynamic Matching Weights = true` allows mod-author Level/Dungeon MatchingProperties to be injected again on every landing.

Fresh S1.42Z runtime evidence on Offense showed the resulting effective pool was still strongly unequal, including values such as LiminalHouse `300`, Sub Systems `275`, Abandoned Foundry `250`, Shatteredrooms `75`, Lead Factory `70`, Spelunkers Caverns (Random) `50`, Crimson Keep `35`, Gray Apartments `25`, DeepcoreMines `25`, and several interiors at `20`, while many others were `100`.

S1.42AA therefore applies the narrow supported owner-level change:

`Inject Dynamic Matching Weights = true`

->

`Inject Dynamic Matching Weights = false`

The intent is to stop author MatchingProperties from re-overriding the already normalized project configuration.
