## Decision

A narrowly scoped deterministic Art Gallery selector is technically designable from existing repository-proven selector infrastructure without changing Art Gallery availability or unrelated gameplay semantics.

The safest reusable precedent is the **selector-only S1.42AK-BMDSFIX1-DIAG1 architecture**, not the larger BMGHDIAG3/BMAF diagnostic architecture.

The selected design is:

> Apply exactly one post-normalizer Harmony postfix to LethalLevelLoader's exact `DungeonManager.GetValidExtendedDungeonFlows(ExtendedLevel, bool)` result, validate that **Art Gallery / `MuseumInteriorFlow` already exists uniquely in the ordinary Offense viable pool at normalized rarity 100**, and only then reduce that fresh returned list to the **same existing wrapper** as a singleton.

This changes selection outcome only. It does not create availability, register a flow, rewrite rarity, alter generation parameters, or patch traversal.

This preflight does **not** authorize implementation, build/publication, Gale import, controller activation or runtime execution.
