## Failure

The game never reached a usable Main Menu and terminated during startup.

The log reached:
`LethalLevelLoader: Custom Content Processed. Unlocking Main Menu.`

Immediately afterwards the new S1.42D delayed LethalMin reflection/Harmony scan began.

The log ends while that scan is still patching methods and never prints the expected completion marker.

Multiple HarmonyX warnings explicitly state that S1.42D attempted to patch inherited/non-declared methods, for example derived Pikmin types resolving the base `PikminAI.GrabPikmin` implementation.

Conclusion:
**S1.42D is a failed startup candidate. The broad LethalMin reflective patch scan is the primary regression.**

## S1.42E correction

Compatibility plugin v1.3.1:

1. LethalMin scan only considers types whose name contains `PikminEnemy`.
2. Only `DeclaredOnly` methods are inspected.
3. Only actual local enemy interaction methods are patched:
   - `BitePikmin`
   - `GrabPikmin`
   - `GrabPikminWithTongue`
4. Generated RPC wrappers are not patched.
5. Generic PikminAI/PikminItem state-machine methods are not patched.
6. Abstract/PInvoke/bodyless methods are skipped.

Jetpack cleanup:
- S1.42D showed `JetpackItem.Start` resolves inherited `GrabbableObject.Start`;
- that Harmony hook is removed;
- the 140-second target is now applied only to the loaded Jetpack `Item` asset, with a narrow retry until the asset exists.

All S1.42D gameplay/test intentions remain:
- isolated enemies: Thumper/Crawler, Puffer, Baboon Hawk;
- generic invincible-Pikmin enemy grab/bite recovery;
- Jetpack 140s;
- Jetpack `MidAirExplosions = Off`;
- Microwave volume 0.7.
