# Profiles

Installable Gale/r2modman profile archives live here.

## Repository-first rule

Profiles are canonical online artifacts. Future builds should be generated by `.github/workflows/profile-build.yml`, not by asking the user to patch or repackage archives locally.

Because `.r2z` is binary, GitHub Actions also generates a readable mirror under `ProfileSources/<build_id>/`.

Directly uploaded profiles are hash-checked/indexed by `.github/workflows/profile-index.yml` when their path is registered in `EXPECTED_HASHES.json`.
