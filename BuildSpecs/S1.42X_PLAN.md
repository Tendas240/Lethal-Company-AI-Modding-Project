## Why S1.42X branches from S1.42U

S1.42W showed no critical compatibility failure, but its `10 -> 16` Jetpack acceleration target still did not produce a clearly perceptible straight-up lift-off difference. Microwave volume `0.15` remained untested because no Functional Microwave was encountered.

S1.42X is built directly from the accepted S1.42U profile rather than stacking W/V project-local DLLs. It reapplies every desired cumulative configuration value and injects only the two S1.42X project-local DLLs.

### 2. More Ship Upgrades Jetpack progression

Config:

`BepInEx/config/com.malco.lethalcompany.moreshipupgrades.cfg`

#### Jet Fuel

Change:

- `Initial Acceleration Increase = 20 -> 10`;
- `Incremental Acceleration Increase = 20 -> 10`.

Reason:

Jet Fuel is percentage-based on the current `jetpackAcceleration`. Doubling the free S1.42W target from 16f to 32f while halving the percentage from 20% to 10% preserves approximately the same absolute +3.2 acceleration contribution per tier:

- W: `16 × 20% = 3.2`;
- X: `32 × 10% = 3.2`.

Approximate S1.42X acceleration progression:

- base: 32.0;
- first effect level: 35.2;
- next: 38.4;
- next: 41.6;
- next: 44.8.

This keeps the purchased upgrade meaningful without compounding the diagnostic free base increase into extreme percentage jumps.

#### Jetpack Thrusters

Change:

- `Initial Maximum Speed Increase = 25 -> 30`;
- `Incremental Maximum Speed Increase = 20` preserved.

Reason:

The much faster base acceleration reaches the separate maximum-power/speed ceiling sooner. A modest first-tier increase keeps Thrusters relevant while avoiding a large escalation of every tier.

With the upstream 500f base maximum-power constant, approximate progression:

- no Thrusters: 500;
- tier 1: 650;
- tier 2: 750;
- tier 3: 850;
- tier 4: 950.
