## Patch Safety Review

Smallest surface: observational callbacks immediately before five exact existing
calls, plus two concrete Dusk helper prefix/postfix pairs. None suppresses a
method, disables a component or intercepts a global Unity setter.

Inheritance: Janitor -> CodeRebirthEnemyAI -> EnemyAI. KillEnemy calls its native
base cleanup and retains the original body. Other inherited AI/network lifecycle
methods are not patched. The Dusk On.EnemyAI.Start wrapper retains orig(self).
Janitor RPC and coroutine/attachment secondary responsibilities remain native.

State ownership: DawnLib/Dusk owns selection and replacement; CodeRebirth owns
Janitor behavior; Unity owns renderers/meshes. The diagnostic writes only its own
tracking, sampling and atomic log counters, and its own log callback registration.
Exact existing foreign transpilers cause refusal instead of attempting to reorder
or compensate for them. Bounded snapshots do not walk the world.

Reverse/adjacent work to preserve in any future separately authorized runtime
gate: ordinary default and non-default selection, original Start, each receive-
side write, chase reset, player attachment/release, ordinary death/despawn,
network ownership and shared lobby shutdown. No runtime acceptance is claimed by
static checks; no gameplay acceptance of this diagnostic is ever permitted.

Arming: validate all identities/method bodies first; install four Janitor probes,
mesh/material observers, then selector observers; verify explicit Harmony owner
counts; subscribe the log callback and set ready last. Any failure disables
observation, unsubscribes if necessary and invokes harmony.UnpatchSelf().
REFUSED TO ARM preserves normal behavior. Observer exceptions produce INCONCLUSIVE
and disable observation; original instructions are never skipped or replaced.

Forbidden broader alternatives: PatchAll, global SetBlendShapeWeight patch,
candidate/RNG replay, guessed KillEnemy overloads, fuzzy reflection, whole-component
disable, AI/RPC/network state mutation, mesh/material/bone/blendshape writes, global
Object scans, per-frame subtree enumeration, and logging in the Unity callback.
