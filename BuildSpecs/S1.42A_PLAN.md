**Advanced options -> Import all files**

Then:
1. reach Main Menu;
2. host/load a save;
3. land on at least one normal moon;
4. allow a dungeon to actually generate;
5. exit game.

Upload to `RuntimeInbox/Current/`:
- complete `BepInEx/config/` directory as ZIP;
- full `LogOutput.log`.

Only after that evidence exists should S1.42 deep tuning begin.
