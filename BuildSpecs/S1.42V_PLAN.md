### More Ship Upgrades

`BepInEx/config/com.malco.lethalcompany.moreshipupgrades.cfg`

The `Jet Fuel` upgrade directly increases Jetpack acceleration:

- `Initial Acceleration Increase = 20`
- `Incremental Acceleration Increase = 20`

However this only affects the purchased Jet Fuel ship upgrade; it is not an unconditional base-Jetpack acceleration setting.

Therefore:

- if the intended behavior is to buff the purchasable Jet Fuel upgrade, a narrow config-only change such as `20 -> 25` can be used;
- if the intended behavior is a modest always-on base acceleration increase, do not fake it through Jet Fuel or a broad control-scheme switch. Resolve an exact narrow implementation first, and if custom code is required it must receive a Patch Safety Review and should be isolated from unrelated balance changes if practical.

**Do not arm S1.42V until this distinction has been resolved technically.**
