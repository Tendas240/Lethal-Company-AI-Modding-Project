## Why S1.42W branches from S1.42U

S1.42V proved the custom Jetpack architecture at runtime but is not an accepted gameplay baseline because the user requested stronger lift and much lower Microwave volume.

S1.42W is built directly from the accepted S1.42U profile rather than stacking a second Jetpack DLL on top of S1.42V. It reapplies the desired Snail setting and final tuning values and injects only the S1.42W Jetpack DLL. This preserves a clean single-owner project-local Jetpack layer and keeps S1.42V immutable as historical evidence.

### 4. LateGameUpgrades Jetpack progression

Config:

`BepInEx/config/com.malco.lethalcompany.moreshipupgrades.cfg`

#### Jet Fuel

Keep:

- `Initial Acceleration Increase = 20`;
- `Incremental Acceleration Increase = 20`.

Reason: Jet Fuel is percentage-based on `jetpackAcceleration`, so the new 16f base automatically scales its absolute effect. One 20% tier adds 3.2f at base 16 instead of 2.4f at base 12. Increasing this percentage as well would compound the free base buff unnecessarily.

Expected acceleration progression at 20/20:

- no Jet Fuel: 16.0;
- first effect level: 19.2;
- next: 22.4;
- next: 25.6;
- next: 28.8.

#### Jetpack Thrusters

Change:

- `Initial Maximum Speed Increase = 20 -> 25`;
- `Incremental Maximum Speed Increase = 20` preserved.

Reason: the stronger acceleration reaches the independent max-power/speed ceiling sooner. A modestly stronger first Thrusters tier keeps the separate speed-cap progression attractive without aggressively increasing all tiers.

With the upstream 500f maximum-power constant the intended progression is approximately:

- no Thrusters: 500;
- tier 1: 625;
- tier 2: 725;
- tier 3: 825;
- tier 4: 925.
