New binding requirement:
**the Jetpack must not explode from normal/continuous boost use, including the high-speed/mid-air explosion behavior caused by sustained boosting.**

- `MidAirExplosions = OnlyTooHigh`

Available safe configuration:
- `MidAirExplosions = Off`

Jetpack Fixes documents `Off` as disabling high-speed/mid-air explosions; collision with solid geometry can still use its normal crash behavior.

For S1.42D:
- set `MidAirExplosions = Off`;
- specifically validate sustained boosting does not explode the Jetpack;
- if any non-collision usage/overboost explosion path remains, add a narrow compatibility patch rather than globally disabling unrelated damage.

User intent is that the Jetpack should not self-destruct merely because it is used/boosted for too long.
